How to Resize an Image Online

Choose dimensions and export an image for web or sharing.

Resizing changes the pixel dimensions of an image.

Open Image Resizer & Compressor, select an image and enter a width and height. Choose JPG for broadly compatible photos, PNG for graphics that need transparency, or WebP where supported.

Changing dimensions can stretch an image if the width and height do not match its original aspect ratio. Keep the original file and compare the output before publishing.
