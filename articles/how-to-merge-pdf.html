How to Merge PDF Files Online

Learn how to combine multiple PDF files into one document.

Combining PDF files can make a report easier to share, print or archive.

Open the Merge PDF tool. Select at least two PDF files in the order you want them to appear, then run the merge. Download the resulting PDF and check the page order, orientation and readability.

If a PDF is password-protected or damaged, the browser library may not be able to open it. Try exporting an unlocked copy from the app that created it, if you are authorized to do so.
