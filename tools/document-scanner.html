Document Scanner

Capture document pages, improve readability and combine images into one PDF.

Free to use — no sign-up required.

Use Document Scanner

Take a photo or select multiple pages, enhance them, then download one PDF.

How to use this tool

  1. Take a photo or select one or more document images.
  2. Choose a scan enhancement and tap Prepare scan.
  3. Review the scanned pages, then select Save scanned PDF.

Frequently asked questions

Is this tool free?

Yes. This version is free to use and does not require an account.

Are my scan images uploaded?

This static version is designed for browser-side processing where supported. Third-party libraries may load from CDNs. Avoid shared devices for sensitive documents.

Does this automatically crop page corners?

You can use automatic edge detection when the OpenCV library loads, or adjust all four corners manually. Review every page before sharing.
